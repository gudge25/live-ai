# Proposal

## Why

Наразі after дзвінка лишається лише проміжна/фінальна репліки в UI під час розмови — коли дзвінок завершується, розширення нічого не показує про зміст розмови, і оператору доводиться прокручувати історію реплік вручну, щоб згадати деталі. AssemblyAI, який ми вже використовуємо для стрімінгу, з 31.03.2026 замінив LeMUR на LLM Gateway — єдиний ендпоінт до Claude/GPT/Gemini під тим самим `ASSEMBLYAI_API_KEY`, тож коротке резюме розмови можна додати без нового провайдера, нового ключа чи нової оплати.

## What Changes

- Після завершення розмови (`onEnd()` у `apps/server/src/app.ts`) бекенд надсилає зібраний фінальний транскрипт (обидві сторони) в AssemblyAI LLM Gateway (`POST https://llm-gateway.assemblyai.com/v1/chat/completions`) з коротким системним промптом і отримує текстове резюме.
- Нова подія в спільному контракті (`packages/shared/src/events.ts`) несе це резюме до клієнта, коли воно готове (окремо від `session_ended`, оскільки генерація резюме займає час і не повинна затримувати завершення сесії в UI).
- Chrome-розширення показує резюме в картці завершеного дзвінка (той самий блок історії, що обмежений `UI_HISTORY_LIMIT`), як тільки подія приходить; якщо резюме ще не готове або запит до LLM Gateway провалився, картка лишається без резюме (без ретраїв, без плейсхолдера помилки, що блокує UI).
- Нова конфігурація: модель LLM Gateway (з дефолтом) та вмикання/вимикання фічі; секрет лишається тим самим `ASSEMBLYAI_API_KEY`.

## Impact

- Новий код: HTTP-клієнт до `llm-gateway.assemblyai.com` (сервер), нове поле/подія в `packages/shared/src/events.ts`, обробка в `apps/server/src/app.ts` `onEnd()`, рендер резюме в Chrome-розширенні.
- Зовнішні залежності: жодних нових — той самий `ASSEMBLYAI_API_KEY`, той самий рахунок AssemblyAI (LeMUR sunset 31.03.2026, LLM Gateway — його заміна).
- Приватність: фінальний транскрипт розмови додатково йде в LLM Gateway (а отже — до сторонньої LLM-моделі, напр. Claude) для резюмування; те саме застереження, що вже застосовується до самого AssemblyAI streaming, поширюється і сюди.
- Non-goals: без збереження резюме довше, ніж уже тримається історія сесій (`UI_HISTORY_LIMIT`), без регенерації/редагування резюме, без підтримки інших LLM-провайдерів окрім AssemblyAI LLM Gateway.
