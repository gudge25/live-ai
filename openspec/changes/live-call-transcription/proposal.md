# Proposal

## Why

Операторам (наприклад, внутрішній номер 222) потрібна живa текстова розшифровка розмови прямо під час дзвінка — без запису файлів і без ручного запуску. Asterisk уже дає все потрібне (ARI по WSS, snoop-канали, AudioSocket через externalMedia), а AssemblyAI Universal-Streaming дає розпізнавання з низькою затримкою, тож можна зібрати це як окремий сервіс поруч із PBX, не змінюючи діалплан.

## What Changes

- Новий бекенд-сервіс `live-ai`, який:
  - підключається до Asterisk ARI по WSS (події) + HTTPS (REST), автоматично перепідключається;
  - стежить за списком внутрішніх номерів (конфіг, напр. `222`) і визначає момент, коли номер реально розмовляє (канал в стані `Up` і в бріджі);
  - «підслуховує» розмову через ARI snoop-канали і виводить аудіо на свій AudioSocket-сервер через `externalMedia` (encapsulation=audiosocket);
  - стрімить аудіо кожної сторони розмови в AssemblyAI realtime і отримує проміжні та фінальні репліки;
  - транслює діалог по WebSocket у клієнтський UI;
  - коректно прибирає snoop/externalMedia/бріджі та сесії AssemblyAI, коли дзвінок завершується.
- Нове Chrome-розширення (MV3) з плаваючим вікном / side panel, яке підключається до бекенду і показує діалог у реальному часі (хто говорить, проміжний текст, фінальні репліки).
- Змін у діалплані Asterisk не потрібно; потрібні лише ARI-користувач, увімкнений HTTPS/WSS для ARI і модулі `res_ari`, `chan_audiosocket`/`res_audiosocket`.

## Capabilities

### New Capabilities
- `pbx-call-monitoring`: з'єднання з Asterisk ARI по WSS, відстеження налаштованих внутрішніх номерів, визначення початку/кінця розмови.
- `call-audio-tap`: підключення до активної розмови через snoop + AudioSocket (externalMedia), окремі потоки для кожної сторони, прибирання ресурсів.
- `realtime-transcription`: стрімінг аудіо в AssemblyAI realtime, отримання проміжних/фінальних реплік з прив'язкою до сторони розмови.
- `transcript-overlay`: WebSocket-трансляція діалогу та Chrome-розширення з плаваючим вікном для його відображення.

## Impact

- Новий код: бекенд (Node.js/TypeScript) + Chrome extension (MV3).
- Зовнішні залежності: Asterisk 18+ з ARI (рекомендовано 20/22), AssemblyAI API key (платний трафік за хвилини аудіо).
- Мережа: бекенд має бути досяжний з Asterisk по TCP (порт AudioSocket), Asterisk — з бекенду по WSS/HTTPS (порт ARI, зазвичай 8089); браузер — з бекенду по WS(S).
- Приватність: розмови передаються в сторонній сервіс (AssemblyAI) — потрібне погодження/повідомлення абонентів згідно з політиками компанії.
